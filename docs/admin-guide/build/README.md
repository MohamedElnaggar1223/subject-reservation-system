# Regenerating the coordinator's guide

`../index.html` and `../img/` are written by `gen.py` from `steps.py` (every step's words, part by part) and the drive's screenshots. Parts A (review and open the pre-loaded June 2027) and C (June 2028 by copying) are scored by their step counts (COORDINATOR_REWORK.md §13, P4: at most 40 and 30); `gen.py` works the counts out, refuses a part over its limit and writes them into the page. To change the words only, edit `steps.py` and run `python3 gen.py`: a screenshot missing from `SHOTS` (default `/tmp/ag/shots`) is kept from `../img/`. Then check the page offline with `node check-page.mjs` (every image loads, every link inside the page resolves, no request leaves the file; it prints each part's step count).

When the screens change, take the screenshots again with `drive/run-all.sh`. `npm install` in this folder first (it gives the drive and the check `playwright-core`; they use the installed Chrome), and run the web against the API port the script will use (`cd apps/web && NEXT_PUBLIC_API_URL=http://localhost:3299 npx next dev --webpack -p 3300`; set `API_PORT`, `WEB_PORT`, `DB`, `OUT` to change them). The script recreates the database `DB` in the `igcse-dev-db` container, migrates it, starts its own API on it (the board's list loads at its start), signs the admin up on the sign-up page and promotes it with the db seed, loads the June 2027 pre-load with its placeholder teachers (it refuses to run while the git-ignored local file of real teachers' names exists), and drives every part through the screens in the guide's order: `a0-team` (the staff on Team), `a1-review` (Part A), `b0-families` (families made at the desk), `b1-parent` and `b2-desk` (Part B), `c1-copy` (Part C). Each JPEG is 1280×900 and under 150 KB, named as `steps.py` names it; the figures each script read on the screens go to `OUT/*-facts.json`. It stops only the API it started, then runs `gen.py` and `check-page.mjs`. Never run the drive against the deployed system: it builds a practice copy.

`drive/contact.mjs` (a folder of shots) and `drive/page-contact.mjs` (the generated page, and its print to PDF) make contact sheets for a review; they are not part of the run.
